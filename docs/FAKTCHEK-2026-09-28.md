## Для vault — предложение навыку `adversarial-citation-factcheck`

- `export.arxiv.org` теперь отвечает 301 на https: `curl -s http://…` без `-L` молча
  возвращает пусто — легко принять за «не существует». Запрашивать по https.
- Обходы блокировок: OpenAI (403) — через веб-архив; Springer — через Crossref API;
  PMC — через Europe PMC; vovr.elpub.ru — через КиберЛенинку; EUR-Lex — через хранилище
  Publications Office; perplexity.ai и help.openai.com — поиском, ограниченным доменом.
- WebFetch трижды исказил данные (контекст Alice AI «32k» — это бенчмарк; Math-Net.Ru —
  дважды, второй раз выдумал название статьи и фамилию «Sviridonov»). Math-Net.Ru отдаёт
  страницы в cp1251: читать `curl … | iconv -f cp1251 -t utf-8`, а не пересказом.
