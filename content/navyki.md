Навык — папка с файлом `SKILL.md`: ваш помощник, упакованный один раз. Что это и как
собрать свой — в [бонусном уроке 1](/bonus-navyki/).

## Как поставить — коротко

- **Perplexity** — «Настройка» → «Навыки» → «Создать навык» → «Загрузить навык», выбрать
  zip с кнопки «Скачать zip». Загрузка своих навыков и библиотека встроенных работают и на бесплатном тарифе
  (проверено автором курса 28.09.2026); создать навык разговором с Computer — только
  с лимитами платного тарифа. Пределы, проверенные автором: в архиве навыка — до 100
  файлов; за одну загрузку — до 5 навыков, остальные — следующими загрузками; описание —
  не длиннее 1024 байт.
- **Claude** — для claude.ai и приложения Claude берите кнопку «zip для Claude»: в нём
  папка навыка в корне архива, как требует claude.ai. Включите «Settings → Capabilities →
  Code execution and file creation», затем «Customize → Skills → «+» → Create skill →
  Upload a skill» `[по справке Anthropic, 02.11.2026]`. Для Claude Code — папка навыка
  в `~/.claude/skills/`; подробнее — [документация Anthropic](https://platform.claude.com/docs/en/agents-and-tools/agent-skills/overview).
- **Бесплатно, в любой нейросети** — распакуйте zip, приложите файлы к новому чату
  и напишите первым сообщением: «Следуй инструкции из файла SKILL.md; остальные файлы —
  справочники к ней». Если сервис не принимает `.md`, переименуйте файлы в `.txt`.

## Как открыть и поправить

Распакуйте zip в папку «Мои навыки» и откройте её в бесплатном
[Obsidian](https://obsidian.md/download) как хранилище: шапка навыка видна полями,
ссылки на справочники открываются щелчком. Две настройки для своих навыков и ловушка
со служебной папкой `.obsidian` — в [бонусном уроке 1](/bonus-navyki/#obsidian).
