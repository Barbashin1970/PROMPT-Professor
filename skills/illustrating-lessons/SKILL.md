# Иллюстратор лекций

Навык превращает замысел преподавателя — «нужна картинка к слайду про…» или найденный
образец — в точные промпты для бесплатных генераторов изображений Алиса AI и GigaChat.
Сам навык не рисует: он готовит промпт, по которому рисует сервис.

## Порядок работы

Скопируй чек-лист в ответ и отмечай шаги:

```
Иллюстрация:
- [ ] 1. Задача ясна: слайд, аудитория, формат, сервис
- [ ] 2. Сценарий выбран: образец / короткий запрос / улучшить промпт / разбор неудачи /
      код в JSON / своё фото в сцене / паспорт стиля
- [ ] 3. Блоки заполнены по формуле
- [ ] 4. Проверка по правилам пройдена
- [ ] 5. Ответ выдан по формату
```

**1. Задача.** Узнай, к какому слайду или теме картинка, для кого, в каком формате (для слайда —
16:9) и где будут рисовать. Не хватает данных — задай до трёх вопросов с вариантами ответа
(стиль, настроение, формат) или предложи разумные умолчания и скажи какие.

**2. Сценарий.**

- **Образец.** Пользователь приложил картинку: разложи её по 11 блокам
  ([references/bloki.md](references/bloki.md)), назови стиль по библиотеке
  ([references/stili.md](references/stili.md)) и отдельно — особый приём автора (свет,
  фактура, линии). Затем составь промпт с **содержанием пользователя**, а не с содержанием
  образца: от образца берутся приёмы.
- **Короткий запрос** («нарисуй энтропию»): предложи образ, который помогает понять слайд,
  и дай три промпта — краткий (30–50 слов), стандартный (80–120), подробный (150–250).
- **Улучшить промпт:** разбери присланный промпт по блокам — что есть, чего не хватает,
  что противоречит, — и дай исправленную версию.
- **Разбор неудачи:** попроси картинку и промпт, назови причину и дай правку — одно
  изменение за раз.
- **Код в JSON.** Просят «код картинки», «JSON-промпт», «разложи в JSON»: разложи образец
  или замысел по 11 блокам в JSON — ключи `subject`, `action`, `setting`, `lighting`, `color`,
  `style`, `composition`, `camera`, `mood`, `quality`, `negative` (соответствие блокам —
  в [references/bloki.md](references/bloki.md)); значения по-русски и конкретно. После JSON —
  краткая версия той же сцены одним абзацем: её вставляют туда, где длинный код
  не принимается. Если на образце человек, его лицо, черты и возраст не описывай:
  в `subject` — «человек с приложенного фото» и одежда.
- **Своё фото в сцене.** Есть код сцены и фото самого пользователя: дай промпт для режима
  редактирования фото Алисы AI — перенести человека в сцену, сохранив лицо, черты, причёску,
  цвет волос, возраст и телосложение; менять окружение, свет, позу, одежду, цвета и обработку;
  ничего сверх кода не добавлять. GigaChat загруженные фото только описывает, поэтому этот шаг —
  в Алисе AI. После результата — сверка с кодом по полям и одна правка за раз.
- **Паспорт стиля.** Серия по одному образцу: JSON только с полями `style`, `lighting`,
  `color`, `composition`, `quality`, `negative`, без объектов и людей образца; затем
  по промпту на слайд — паспорт плюс свои `subject`, `action` и `setting`.

**3. Формула.** `[стиль] — [объект], [действие], [окружение], [свет], [цвет],
[композиция и формат], [камера], [настроение], [качество]. Без: [что исключить].`
Для слайда обычно хватает первых семи блоков.

**4. Проверка.** Перед выдачей сверь каждый промпт с правилами ниже. Нашёл нарушение —
исправь и проверь снова.

**5. Формат ответа:**

```
Образ: [одна фраза — что нарисовать и зачем это слайду]

Промпт — краткий: [...]
Промпт — стандартный: [...]
Промпт — подробный: [...]

Как рисовать: Алиса AI — «Нарисуй» и промпт, формат можно указать в запросе;
GigaChat — «Нарисуй» и промпт; если в диалог уже загружали картинку — в новом диалоге;
ещё бесплатно — Шедеврум (shedevrum.ai) и Qwen Chat (режим Image Generation).

Если не вышло: [1–2 правки на частые сбои]
```

Для серии — сначала общий блок стиля (техника, свет, цвет, формат), затем по промпту на слайд:
общий блок плюс свой объект.

Для кода в JSON:

```
Код картинки (JSON):
{
  "subject": "...",
  "action": "...",
  "setting": "...",
  "lighting": "...",
  "color": "...",
  "style": "...",
  "composition": "...",
  "camera": "...",
  "mood": "...",
  "quality": "...",
  "negative": "..."
}

Краткая версия: [та же сцена в 2–3 предложениях]

Как применить к своему фото: Алиса AI → режим редактирования → приложить своё фото
(JPEG или PNG до 20 МБ) → промпт «Примени к моему фото код сцены: лицо, черты, причёску
и возраст не меняй; меняй окружение, свет, позу, одежду и обработку, как в коде».
```

Разобранный пример — в [references/primery.md](references/primery.md), пример 3.

## Правила — и зачем они

- **Конкретно**: «три колбы с зелёной жидкостью», а не «колбы» — иначе число и вид выберет
  модель.
- **Главное — в начале**: стиль и объект первыми — так их труднее потерять в длинном промпте.
- **Что нужно, а не чего не нужно**: «яркий день», а не «не тёмный»; исключения — отдельным
  блоком «без».
- **Без надписей на картинке**: буквы модель может исказить; текст добавляют в редакторе
  презентаций.
- **Формат словами**: «горизонтальный формат 16:9». Параметры Midjourney вроде `--ar` в Алисе
  AI и GigaChat не нужны.
- **Без противоречий**: «фотореализм» и «масляная живопись» вместе спорят.
- **Язык**: промпт можно дать по-русски или по-английски; английские промпты из коллекции
  работают как есть.
- **Место под заголовок**: для обложек и фонов — «свободное место слева (справа, сверху)».
- **JSON — те же 11 блоков**: ключи ровно эти, значения конкретные; ненужный блок — пустая
  строка, а не выдуманное значение (у рисованной иллюстрации нет `camera`). Код удобно
  править по одному полю — так пользователь видит, что именно поменял.
- **Код не переносит чужую внешность**: он описывает сцену, позу, свет и обработку, а не лицо
  человека с образца — иначе это уже чужие персональные данные.
- **Историческая сцена — не документ**: «фотография» и «фотореализм» делают кадр похожим
  на архивный снимок. Для истории лучше «реалистичная цифровая иллюстрация» и подпись
  на слайде «реконструкция нейросетью, не источник»; детали эпохи сверять с музейными
  материалами.

## Чего не делать

- **Не копировать чужое произведение**: образец задаёт приёмы, содержание — пользователя.
  Узнаваемую чужую картину целиком не воспроизводить.
- **Не рисовать реальных людей по фото без их согласия** — студентов, коллег: это
  персональные данные, а условия GigaChat прямо запрещают загружать чужие персональные
  данные. Своё фото пользователь прикладывает сам — для сценария «своё фото в сцене».
- **Не обещать права на коммерческое использование**: на бесплатных тарифах Алисы AI
  и GigaChat картинки — для личных некоммерческих целей; для иного пусть пользователь
  проверит условия сервиса.
- **Не выдумывать возможности сервисов**: не знаешь, умеет ли сервис что-то, — так и скажи.
- **Не раздувать промпт** больше 250 слов: длиннее — не точнее.
