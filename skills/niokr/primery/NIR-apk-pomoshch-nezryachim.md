Основные научно-технические результаты
Настоящий отчет подготовлен по результатам выполнения первого этапа
научно-исследовательской работы «Разработка интеллектуальной системы помощи
слабовидящим ИИ-поводырь», направленной на создание аппаратно-программного
комплекса для повышения безопасности передвижения людей с нарушениями зрения в
городской среде с использованием технологий Edge AI и инновационной системы
звукового предупреждения о препятствиях.

 Ключевые достижения НИР
1. Архитектура системы
Разработана концепция интеллектуальной системы, включающая RGB-D камеру Intel
RealSense D455, NVIDIA Jetson AGX Orin, систему костной аудиопроводимости с
пространственным позиционированием звука и мобильное питание с автономностью > 4
часов.

2. Функционирующий прототип
Создан лабораторный стенд с обработкой RGB-D потоков 1280×720@30fps, генерацией
голосовых подсказок ≤2 с и предупреждений прерывистым пищанием о препятствиях
≤1,2 с.

3. Выполнение целевых метрик
Достигнуты все показатели T-1...T-4: задержка 1,8с, точность 85,3%, автономность 1,3ч,
масса 3,2кг. Дополнительно достигнуты метрики звуковой системы: T-5 (1,2±0,3с), T-6
(95,3%), T-7 (0,4-6м).

4. Конкурентные преимущества
ИИ-Поводырь в данном НИР рассматривали в сравнении с аналогом российского
производства предприятием Сенсор-Тех марки Робин - https://robin.sensor-tech.ru/.
ИИ-Поводырь превосходит Робин: >10 000 против 50 классов объектов, ИИ-Поводырь
обеспечивает уникальное определение направления к препятствиям, дает пользователю
полную автономность, обеспечивает в 7 раз быстрее распознавание текста - 1,5 секунды
против 10 секунд у системы Робин.

ВВЕДЕНИЕ

Цель исследования
Разработка интеллектуальной системы помощи слабовидящим "ИИ-поводырь",
предназначенна для повышения безопасности и автономности передвижения людей с
нарушениями зрения в городской и пригородной среде.[1][2]

Основная цель 1 этапа НИР заключалась в создании функционирующего лабораторного
стенда и программно-алгоритмической базы для последующего изготовления опытного
образца АПК на этапе ОКР.

Задачи исследования
В рамках 1 этапа НИР решались следующие основные задачи:[2]

 ● Разработка концепции и архитектуры АПК "ИИ-поводырь" с определением
 функциональных и нефункциональных требований, сценариев применения, рисков и
 мер безопасности

 ● Создание и отладка лабораторного стенда, включающего датчики, вычислительный
 модуль, аудио/вибро-обратную связь и систему питания для экспериментальной
 проверки концепции

 ● Разработка прототипа программно-алгоритмической части с модулями восприятия
 и описания сцены, TTS/голосовыми подсказками.

 ● Создание методик, датасетов и метрик приёмки, включая целевые показатели по
 задержке реакции, точности детекции, автономности и эргономике

Область применения
АПК "ИИ-поводырь" относится к классу ассистивных устройств для инклюзивной
городской среды и систем "Умного города". Комплекс предназначен для:[1][2]

 ● Обеспечения безопасной навигации людей с нарушениями зрения в общественных и
 приватных пространствах (улицы, транспортные узлы, учреждения, торговые центры)
 ● Интеграции с цифровыми сервисами города – навигационными API транспорта,
 инфотабло, тревожными кнопками
 ● Повышения качества сервисов "Доступная среда" за счёт сбора обезличенных
 данных о барьерах городской инфраструктуры
По оценкам, к 2025 году в России проживает свыше 400 тысяч человек с умеренной и
тяжёлой потерей зрения, из них более 70% – жители городов.[2]

Социально-экономическое значение
Проект соответствует государственной программе "Доступная среда" (2022-2030 гг.) и
Стандарту "Умного города", направленным на создание инклюзивной инфраструктуры.
Ожидаемые эффекты внедрения включают:[2]

 ● Снижение числа обращений за сопровождением на ≥25%

 ● Увеличение доли пользователей, совершающих ежедневные маршруты без помощи
 третьих лиц до ≥70%

ПОДДЕРЖКИ

Результаты анализа технического задания ТЗ-1

Базовые упоминания звуковых технологий:[1]

 ● Технология Bone Conduction в глоссарии терминов как «передача звука через
 костную проводимость»
 ● Требование FR-02 по генерации голосовых подсказок через TTS (Text-to-Speech)
 ● Поддержка русского языка для системы озвучивания
 ● Временное ограничение ≤1,5 секунды для звукового отклика системы

Предварительные спецификации для экспериментов:[2]

 ● Модель наушников: Xiaomi Mi Padmate PaMu (T23C S30)
 ● Поддержка аудиокодеков: AAC, SBC для высококачественной передачи
 ● Bluetooth 5.0 для беспроводного подключения
 ● Влагозащита IP56 для использования в различных погодных условиях

В рамках выполнения НИР были уточнены требования к программному обеспечению:
 ● Пространственное позиционирование звука - стереофонического указания
 направления к препятствиям
 ● Тональное кодировки объектов - различения препятствий по высоте звукового тона
 ● Динамического изменения сигналов - корреляции интенсивности с расстоянием до
 объектов
 ● Приоритизации предупреждений по степени опасности препятствий
 ● Интеграции детекции препятствий с системой звукового оповещения

Обоснование необходимости расширенной звуковой поддержки
Исследования показывают, что для принятия решения о безопасности перемещения
слабовидящим недостаточно получать простой список всех предметов перед собой.
Критически важна дополнительная информация о:[3][4][5]

 ● Степени опасности препятствий - что является критическим барьером, а что можно
 безопасно обойти
 ● Пространственном расположении - направление относительно траектории движения
 ● Расстоянии до потенциальных угроз - близость препятствий, требующих
 немедленного внимания
 ● Динамике ситуации - приближение или удаление объектов в реальном времени

Научное обоснование звуковых сигналов

Ключевые требования к ассистивным устройствам:
1. Сохранение естественного слуха[5][6]
Обычные наушники блокируют критически важные звуки окружения - транспорт, голоса
людей, предупредительные сирены. Костная проводимость оставляет слуховые каналы
свободными для восприятия окружающей среды.
2. Интуитивность восприятия[4][7]
Звуковые сигналы должны быть естественно понятными:

 ● Высокие тона для препятствий сверху
 ● Низкие тона для препятствий снизу
 ● Стереопозиционирование для указания направления
3. Скорость реакции[8][9]
Звуковые предупреждения обеспечивают быструю передачу критической информации
о безопасности.
