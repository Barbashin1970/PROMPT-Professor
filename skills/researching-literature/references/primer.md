## Фаза 1. План

**Вопрос исследования:** какие педагогические методики наиболее эффективны в преподавании
программирования студентам с разным уровнем подготовки — новичкам, среднему уровню, продвинутым.
**Трек:** научный

**Рамка вопроса (PICOS)**
- P — студенты вузов, изучающие программирование, с разным уровнем подготовки
- I — методики: активное обучение, парное программирование, проектное обучение,
  перевёрнутый класс, геймификация
- C — традиционный формат «лекция и самостоятельная работа»
- O — успеваемость, отсев, вовлечённость, сохранение знаний
- S — эмпирические исследования, систематические обзоры и метаанализы

**Подзадачи**
1. Как исследования делят студентов по уровню подготовки — готово, когда сопоставлены
   классификации, которыми пользуются авторы.
2. Какие методики изучались — готово, когда составлен перечень методик с определениями.
3. Эффективность методик для новичков — готово, когда по каждой методике есть вывод
   с уровнем уверенности или отмечен пробел.
4. Эффективность для среднего уровня — готово на тех же условиях.
5. Эффективность для продвинутых — готово на тех же условиях.
6. Универсальные и особые методики — готово, когда сведены выводы подзадач 3–5.

**План поиска**
- Базы и источники: ACM Digital Library (конференции по преподаванию информатики),
  IEEE Xplore, ERIC, Google Академия, eLIBRARY.RU, КиберЛенинка
- Ключевые слова: «преподавание программирования», «парное программирование», «перевёрнутый
  класс» / "programming education", "introductory programming", "pair programming",
  "active learning"
- Период: уточнить
- Языки: уточнить
- Типы публикаций: уточнить

**Критерии отбора**
- Включаем: эмпирические исследования в вузах; описан уровень подготовки студентов;
  измерен хотя бы один результат из O.
- Исключаем: школьное обучение; описания курсов без измерения результатов.

**Критерии качества:** методическая строгость, прозрачность данных, независимость,
воспроизводимость, рецензирование.

**Допущения и ограничения:** «эффективность» понимается через результаты из O; уровень
подготовки — так, как его определяют сами авторы.

**Нужно уточнить**
1. Период публикаций — предложение: последние десять лет.
2. Языки — предложение: русский и английский.
3. Типы публикаций — предложение: рецензируемые статьи и обзоры.
4. Для чего нужен обзор: статья, обновление рабочей программы, НИР — от этого зависит

## 6. Что в примере сделано намеренно

- Вместо настоящих источников — заглушки: модель не должна принимать их за найденные работы.
- Период, языки и типы публикаций задал пользователь; модель только предложила варианты.
- Счётчики сходятся с таблицей: 5 = 3 + 1 + 1. Строки «найдено в базе» нет — база
  этого числа не показывала.
- Файл без идентификатора (И-4) не включён и не участвует в выводах, пока пользователь
  не пришлёт DOI или ссылку.
- Работа, известная по чужому списку литературы, стоит в «Не открыто», а не в реестре.
- Источник, прочитанный только по аннотации, получил «не оценено», а вывод на нём одном —
  низкую уверенность.
- Каждый ответ заканчивается одной концовкой: проверка, статус, варианты «Дальше».
