## 1. Как собирать отчёт

- **Только из готового.** Отчёт собирается из реестра источников и таблицы доказательств
  фаз 2–3. Новых источников в фазе 4 нет: понадобился новый — вернуться к фазе 2.
- **Действия фазы:** свести выводы подзадач (где согласуются, где противоречат); найти
  сквозные закономерности; истолковать их применительно к вопросу; оценить силу
  доказательств и назвать пробелы.
- **Каждое утверждение — со ссылкой** `[И-3]`; числа и цитаты — со страницей, если она есть:
  `[И-3, с. 12]`.
- **Счётчики раздела 4.1** — те же, что в реестре фазы 2, и сходятся:
  всего = включено + исключено + не проверено.
- **Рекомендации — обобщённые.** План внедрения — следующий шаг пользователя; отчёт говорит
  это прямо, в разделе 6.2.
- **Стиль:** русский научный, формально и доказательно, без абсолютных формулировок там,
  где уверенность средняя или низкая. Формулы — в LaTeX, если среда его отображает.
- Шаблон показан в рамке кода только для наглядности; в ответе — обычный текст с разметкой.

## 2. Шаблон отчёта

```
# <Название обзора>

## 1. Краткое резюме
<200–300 слов — для кафедры, руководителя НИР, учёного совета>
**Вопрос исследования:** <…>
**Ключевые выводы:**
- <вывод> [И-…] — уверенность: высокая
- <вывод> [И-…] — уверенность: средняя
- <вывод> [И-…] — уверенность: низкая
**Рекомендации (обобщённые):**
- <…>
**Главные ограничения:** <…>

## 2. Введение
2.1. Вопрос исследования: <PICOS или ключевые вопросы и факторы PESTLE>
2.2. Цели обзора: <…>
2.3. Обоснование: <почему вопрос важен для курса, кафедры, НИР>

## 3. Методика
3.1. Тип обзора: систематический | прикладной | смешанный
3.2. Стратегия поиска: базы; строки поиска; период (согласованный с пользователем); языки; типы публикаций
3.3. Критерии отбора: включения; исключения
3.4. Оценка качества: чек-лист качества и уровни доказательности
3.5. Метод синтеза: повествовательный синтез | тематический анализ | <другой>

## 4. Результаты
4.1. Отбор источников (по реестру)
- В реестре — открыто или приложено: <N>
- Включено: <M>
- Исключено: <K> — причины: <…>
- Не проверено: <L> — причины: <…>
- Объединено дубликатов и версий: <D>
- Не открыто (вне реестра): перечень — в разделе 7.2

4.2. Результаты по подзадачам
**Подзадача 1. <название>**
- <вывод> [И-1, И-3] — уверенность: <…>
- Противоречия: <…>
- Пробелы: <…>

4.3. Сквозные выводы
- Закономерности: <…> [номера источников]
- Главные наблюдения: <…>

## 5. Обсуждение
5.1. Истолкование: что результаты значат для вопроса исследования
5.2. Ограничения
- методические: <…>
- данных: <например, часть источников прочитана только по аннотациям; поиск ограничен доступными базами>
- внешние: <…>
- порядок работы: <если фазы шли без согласования с пользователем — сказать об этом>
5.3. Уровни уверенности
- высокая: <выводы>
- средняя: <выводы>
- низкая: <выводы>

## 6. Выводы и рекомендации
6.1. Основные выводы — каждый с силой доказательств
6.2. Рекомендации — обобщённые. План внедрения (что, кто и когда меняет в курсе, на кафедре,
     в НИР) — следующий шаг пользователя: для него нужны сведения о ресурсах и сроках,
     которых в литературе нет.
6.3. Направления дальнейших исследований — пробелы из раздела 4

## 7. Список источников
7.1. Включённые источники — в порядке упоминания
7.2. Не проверено и не открыто — отдельно, с причиной

## Приложения
А. Протокол поиска — строки поиска по каждой базе
Б. Критерии отбора — развёрнуто, с примерами
В. Чек-лист качества
Г. Полная таблица доказательств
```

## 3. Список источников

- **Правила оформления** — те, что назвал пользователь: требования журнала, диссертационного
  совета, стиль APA. Если не назвал — по ГОСТ Р 7.0.100.
- **У каждой записи** — номер реестра и идентификатор. Запись в разделе 7.1 без
  идентификатора — ошибка: такой источник должен стоять в 7.2.
- **Выходные данные** — из самого источника, а не по памяти.
- **Образец записи** (заглушки в угловых скобках):

  `[И-1] <Фамилия, И. О.> <Название статьи> / <И. О. Фамилия> // <Журнал>. – <Год>. – Т. <…>, № <…>. – С. <…>. – DOI: <…>.`

- **Раздел 7.2:** `[И-3] <выходные данные, сколько известно> — не проверен: нет идентификатора`;
  `<работа из списка «Не открыто»> — не проверен: не открыт`.
