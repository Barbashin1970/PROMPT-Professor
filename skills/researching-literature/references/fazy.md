# Фазы 1–3: действия и шаблоны

Для каждой фазы — что делать, шаблон вывода и варианты «Дальше» для концовки ответа.
Шаблоны показаны в рамке кода только для наглядности; в ответе — обычный текст с разметкой.
Отдельного блока «статус фазы» в шаблонах нет: ответ заканчивается одной общей концовкой.

## Содержание

1. Фаза 1. План
2. Фаза 2. Сбор источников
3. Фаза 3. Оценка источников

---

## 1. Фаза 1. План

### Действия

1. **Уточнить вопрос.** Если постановка допускает разные трактовки — назвать их и предложить
   одну; допущения записать явно.
2. **Выбрать трек:** научный (обзор исследований), прикладной (спрос, рынок, практика других
   вузов) или смешанный.
3. **Задать рамку вопроса:** для научного трека — PICOS, для прикладного — ключевые вопросы
   и факторы PESTLE.
4. **Разбить вопрос на подзадачи** — от 3 до 7; у каждой — критерий готовности
   («готово, когда…»).
5. **Составить план поиска:** базы и другие источники; ключевые слова на русском
   и английском; период, языки и типы публикаций — если пользователь их не назвал,
   предложить вариант в разделе «Нужно уточнить».
6. **Задать критерии включения и исключения.**
7. **Назвать критерии качества:** методическая строгость, прозрачность данных, независимость,
   воспроизводимость, рецензирование.

### Шаблон плана

```
## Фаза 1. План

**Вопрос исследования:** <одна-две фразы>
**Трек:** научный | прикладной | смешанный

**Рамка вопроса (PICOS)** — для прикладного трека вместо неё: ключевые вопросы и факторы PESTLE
- P — кто или что изучается: <…>
- I — вмешательство или явление: <…>
- C — с чем сравниваем: <…> или «сравнение не предусмотрено»
- O — какие результаты важны: <…>
- S — какие типы исследований включаем: <…>

**Подзадачи**
1. <подзадача> — готово, когда: <…>
2. <…>

**План поиска**
- Базы и источники: <…>
- Ключевые слова: <русские> / <английские>
- Период: <согласованный с пользователем> или «уточнить»
- Языки: <…> или «уточнить»
- Типы публикаций: <…> или «уточнить»

**Критерии отбора**
- Включаем: <…>
- Исключаем: <…>

**Критерии качества:** <…>

**Допущения и ограничения:** <…>

**Нужно уточнить**
1. <вопрос> — предложение: <вариант по умолчанию>
```

### Варианты «Дальше» после фазы 1

- [A] Утвердить план и перейти к фазе 2 «Сбор источников» (если остались вопросы — ответить на них)
- [B] Уточнить пункты плана
- [C] Изменить подзадачи или критерии

Фаза 2 не начинается, пока в «Нужно уточнить» остаются период, языки или типы публикаций:
без них поиск нельзя повторить.

## 2. Фаза 2. Сбор источников

### Действия

1. **Искать по каждой подзадаче** по плану: ключевые слова, фильтры периода, языка и типа.
   Если среда не ищет в сети или база закрыта — выдать поисковые строки (шаблон ниже)
   и попросить пользователя приложить найденное.
2. **Открыть каждый источник.** В реестр попадает только открытое или приложенное. Если
   доступна лишь аннотация — пометить «аннотация»: оценка в фазе 3 будет ограничена.
3. **Записать выходные данные и идентификатор из самого источника**, а не по памяти.
   DOI обычно напечатан на первой странице статьи. Нет идентификатора — статус
   «не проверен: нет идентификатора» и просьба к пользователю прислать DOI или ссылку.
4. **Первый отбор** по названию и аннотации: критерии включения и исключения; у каждого
   исключённого — причина.
5. **Убрать дубликаты:** один источник — один номер, даже если он нужен нескольким
   подзадачам; препринт и журнальная версия — одна запись (указать обе).
6. **Работы, известные только косвенно** — по памяти, из чужого списка литературы,
   по строке выдачи, — внести в список «Не открыто»: вне реестра, вне счётчиков, выводов
   не поддерживают.
7. **Посчитать счётчики по реестру:** всего = включено + исключено + не проверено.

```

<…>
```

## 3. Фаза 3. Оценка источников

### Действия

1. **К каждому включённому источнику применить чек-лист качества** (ниже).
2. **Определить уровень доказательности** по дизайну исследования.
3. **Извлечь данные только из прочитанного:** основные результаты, методика, выборка
   (если есть), ограничения, названные авторами, конкретные числа — с номером источника
   и страницей.
4. **Свести данные в таблицу доказательств** по подзадачам.
5. **По каждой подзадаче** назвать, где источники согласны, где противоречат, где пробел.
6. **Найти сквозные темы** по всем подзадачам.
7. **Присвоить выводам уровни уверенности.**

### Чек-лист качества источника

```
- [ ] Методическая строгость: дизайн, выборка, измерения описаны и подходят вопросу
- [ ] Прозрачность данных: данные доступны или подробно описаны
- [ ] Независимость: нет явного конфликта интересов
- [ ] Воспроизводимость: деталей хватает, чтобы повторить исследование
- [ ] Рецензирование: работа прошла рецензию (журнал, конференция) или нет (препринт, доклад)
Итог: высокое | среднее | низкое — и одна фраза, почему.
Прочитана только аннотация — «не оценено: прочитана только аннотация».
```

### Уровни доказательности

- **Высокий** — систематические обзоры, метаанализы, рандомизированные контролируемые испытания.
- **Средний** — отдельные эмпирические исследования: квазиэксперименты, сравнительные,
  корреляционные.
- **Низкий** — мнения экспертов, описания отдельных случаев.

### Уровни уверенности

- **Высокая** — три и более независимых включённых источника согласны.
- **Средняя** — два источника или есть противоречия.
- **Низкая** — один источник или данные противоречат друг другу.

Считаются только включённые источники реестра. Источники из списка «Не открыто»
и со статусом «не проверен» не считаются никогда.
