# Работа по карте: курс, тест, текст

Во всех режимах карта — главный источник. Что нужно для ответа, но в карте нет, не
придумывается: такое место помечается «вне карты» и выносится списком «что уточнить».

## Новый курс по карте

Порядок — обратное проектирование: результаты — проверка — занятия.

1. **Цель курса и 3–5 результатов обучения** — проверяемыми действиями, из рационального
   и ценностного уровней.
2. **Как проверить каждый результат** — задание или вопрос. Неверные пути решения —
   из студенческого уровня.
3. **Таблица модулей:** модуль — результат — тезисы карты — форма практики — что студент
   делает сам, а что вместе с ИИ.
4. **Трудность каждого модуля** — из студенческого уровня — и как её снять.
5. **Вступление к курсу** на 5–7 предложений: эмоциональный и авторский уровни, слова автора.
6. **Вне карты** — что для новой аудитории уточнить у автора.

Проверь перед выдачей:

- каждый результат — действие, которое можно увидеть в работе студента;
- у каждого модуля есть тезисы карты; модуль без тезиса помечен «вне карты»;
- новая аудитория учтена: примеры и задания из её будущей профессии, а не из старого курса;
- в каждом модуле сказано, где ИИ можно, а где студент работает сам.

## Тест по карте

1. Каждый вопрос проверяет тезис рационального уровня: понимание и применение, а не
   определения, которые модель выдаст за секунду.
2. Неверные варианты — из студенческого уровня: типичные ошибки и путаница в понятиях.
   Неверный вариант должен быть правдоподобным для студента, который ошибается.
3. Хотя бы два вопроса — ситуации из контекстного уровня: где это встретится в профессии.
4. Ключ к каждому вопросу: верный ответ; какой тезис карты он проверяет; какую ошибку ловит
   каждый неверный вариант.
5. Вопрос без тезиса в карте — с пометкой «вне карты».

Образец вопроса (условный курс «Статистика для экономистов»):

```
В регионах, где больше кофеен, выше доходы жителей. Что можно сказать по этим данным?
A) Открытие кофеен повышает доходы — ловит: связь принимают за причину
B) Связь есть, но о причине данные не говорят: нужен эксперимент или учёт других факторов — верно
C) Связь случайна: кофейни и доходы — разные вещи — ловит: отрицают связь, потому что не видят механизма
D) Доходы растут, поэтому открываются кофейни — ловит: та же ошибка, только причина перевёрнута
Тезис карты: «Студенты путают корреляцию и причинность» (студенческий уровень)
```

## Текст по карте

1. Что пишем и для кого: анонс курса, пост в канал кафедры, вступление к лекции.
2. Опора: 2–3 тезиса рационального уровня, 2–3 — эмоционального и авторский акцент со
   словами автора из карты.
3. Каждое утверждение текста возводится к тезису карты. Чисел, фактов и обещаний, которых
   в карте нет, не добавлять.
4. Без канцелярита и рекламных штампов: текст должен звучать как автор.

## Обновить карту

1. Внеси новые ответы и материалы, сохрани пометки источников.
2. Сверь расхождения: какие закрыты, какие появились.
3. Под картой — список изменений: добавлено, изменено, убрано и почему.
