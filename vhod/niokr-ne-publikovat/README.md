# Не публиковать

Два образца навыка `niokr` — отчёт о НИР и техническое задание на НИР по беспилотнику.
Тематика непубличная: в тексте метод (архитектура связки вычислителя и полётной прошивки,
синхронизация интерфейсов, планирование, числа замеров) и организация-исполнитель.
Сняты из опубликованного навыка 06.10.2026 по решению автора курса: переименование темы
суть бы не скрыло.

Папка `vhod/` на сайт не выгружается (`.vercelignore`) и в архивы навыков не попадает.
Вернуть образцы в навык — только после экспертизы на возможность открытого опубликования.
